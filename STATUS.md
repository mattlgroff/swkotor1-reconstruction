## c68 integration

The c68 checkpoint adds the end-credits `StopSounds` call, restores the sound-play length return through the reviewed callers, removes the wrong-ABI string-list Add duplicate and the added `SetEventDescriptions` exit guard, and restores the original startup `HD0:TEMP` removal operation. Much of the private harness cleanup was already unnecessary in the public build: its selected window, gamma, capture and event-creation providers already call the real APIs, and the private frame-capture and strict-window harness layers are absent. Those existing public behaviors are preserved rather than credited as new fixes. Remaining fatal binding checks are not silently removed. This is the faithful reconstruction track, not the separate Reforged modernization plan.

These are historical private-candidate observations, not tests of this public executable.

The private launcher and its junction-based layout are not substituted for this public setup.

The c67 x87 changes and automatic local original-derived CRT dependency remain in place. C68's L5 math harness is test infrastructure, not a new full-arithmetic runtime implementation or a byte-identical matching gain. ## c69 and c70 arithmetic integration

This update follows the published c68 integration and carries both intervening private checkpoints: the five c69 units and c70's 17 additional units. C69 covers core46 camera, projectile motion, projectile AI, camera stick and camera navigation. C70 adds creature animation, contested animation, particles, movement actions, module camera, scene3d and 11 movement files: 0811, 0958, 1126, 1128, can-see, direct-line, area VFX position, nearest-object-by-name, nearest enemy, safe location and trigger geometry. These use authored C++ with x87 extended intermediates and explicit original float-store boundaries. The source is reconstruction, not recovered original source.

Each unit was tested privately with 10,000,000 comparisons against the original and independently reviewed. These are finite comparisons within the recorded test domains, not universal arithmetic equivalence. The c70 work fixes two scene3d defects: 00425CA0 now performs floating-point negation, including signalling-NaN quieting, and 0046B7C0 uses the original cross-product order for the fade plane. A test-runner defect that omitted special values in fake-object fills was addressed by repairing and rerunning 32 specs in five units; those reruns were coordinator-checked without a separate independent review.

**The arithmetic plan is not finished.** About 1,500 floating-point functions remain; 31 game functions still call modern CRT math directly, and later L6, L7, L8 and Phase S stages remain. There is no claim of 100% original math or whole-game parity. Some non-floating-point functions were recompiled with clang-cl without a value gate, including about 165 in scene3d and 21 in 0811. The direct-line height path's real provider is outside its value-gated coverage. Mixed signalling-NaN memory operands, existing ownership/exception-path limits and unexplained c69 lag remain limitations.

**Private c70 live test:** the project owner passed one live test on 2026-11-02 from the Endar Spire first Sith fight save, using the normal profile, with a clean exit (code 0). This replaces the checkpoint's earlier "not run" status. It was one test on one level, not a full playthrough. The tested private executable's SHA-256 was `288a2de0d574ad4c704732b5fff521fa9c59ff7065ab37f7fb350ba54b86ad9c`. This historical private-candidate result is not a gameplay test of the rebuilt public executable.

The public port retains the existing source layout and local original-derived L1 dependency. It publishes runtime source and headers, manifest pins and compiler recipes, build flag validation and sanitized status/build documentation. Private diagnostic hooks, mutant switches, differential harnesses/specs, raw receipts and generated original-derived outputs remain excluded. The separate `matching/` track is unchanged.

## Intentionally excluded

Developer Tools, dead/unused Neverwinter multiplayer code, and Cheat Codes are intentionally outside this project's normal single-player gameplay scope. These are deliberate scope exclusions, not unfinished normal single-player gameplay features. This scope decision does not establish that every address in those categories is unreachable or correctly classified, and it does not remove unresolved functions from the recorded stopper census or matching metrics. No implemented code is removed by this documentation change.

The source builds with the Windows toolchain in [BUILDING.md](BUILDING.md).
